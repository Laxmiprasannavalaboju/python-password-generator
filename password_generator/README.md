\# Python Password Generator



\## About the Project



This is a simple Password Generator built using Python.



The program generates random passwords based on the length entered by the user.



\## Features



\- Generates random passwords

\- Allows the user to choose password length

\- Includes uppercase and lowercase letters

\- Includes numbers

\- Includes special characters

\- Handles invalid input

\- Allows the user to generate multiple passwords



\## Technologies Used



\- Python

\- random module

\- string module



\## How to Run



Run the following command:



```bash

python password\_generator.py
